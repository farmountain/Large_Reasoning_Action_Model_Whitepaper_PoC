\subsection{Interpretation}
Removing Prajna expands the candidate space to the raw size and increases oracle queries in proportion. Removing Grover replaces the square-root query count with a linear brute-force count. Removing tier-3 sets the pass rate to the oracle acceptance rate and loses downstream formal guarantees. Removing Reflexion leaves the memory empty and disables critique replay. Each degradation matches the inversion analysis in Section 8.
